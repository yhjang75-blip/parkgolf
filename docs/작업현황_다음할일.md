## 2. 다음에 이어서 할 일 (순서대로)

1. **Render 에 DB 연결 확인** ← 여기서 멈춤
   - Neon 프로젝트 '나이스파크'(싱가포르) 생성 완료. 사용자가 접속 주소를 Render 에 넣었다고 했으나 공개 사이트는 아직 DB 를 못 찾음 (`/api/me` → `{"enabled":false}`).
   - 확인할 곳: Render → parkgolf → **Environment** 에 `DATABASE_URL` 이 있는지, **Logs** 에서 `데이터베이스` / `회원 기능` 검색.
   - 로그 문구 뜻: `DATABASE_URL 이 없습니다` = 값이 안 들어감 · `연결 실패 … password` = 비밀번호 틀림 (Neon 에서 Reset password 후 다시 넣기) · `연결 성공` = 완료.
   - Neon 화면에서 '비밀번호 표시'·'코드 조각 복사'를 누르면 오류 화면이 나왔음 → **Reset password** 로 새 주소를 받는 방법을 씀.
2. **카카오 로그인 켜기** (카카오 개발자 → 앱 '파크골프장 통합예약시스템', ID 1646134)
   - 카카오 로그인 사용 ON
   - Redirect URI: `https://parkgolf.onrender.com/auth/kakao/callback`, `http://localhost:5000/auth/kakao/callback`
   - 동의항목: 닉네임·프로필 사진 필수
   - Render Environment 에 `KAKAO_REST_API_KEY` 추가 (대화에 노출된 기존 키는 재발급 권장)
3. **공개 사이트에서 가입·글쓰기·사진 올리기 확인**
4. **관리자 지정**: 운영자가 가입 → '내 정보' 아래 회원번호(`kakao:숫자`) 확인 → Render 에 `ADMIN_KAKAO_IDS` 추가
5. **운영 정보 채우기** (`data/site.json`): 운영자 이름(개인정보 보호책임자), 문의 이메일, 제휴 문의처 — 개인정보처리방침에 법적으로 필요
6. **제휴 혜택 등록**: 제휴처·상품이 정해지면 `/admin` 에서 등록

## 3. 알아 둘 점

- 대회 일정(`data/media.json` 의 `tournaments`)은 사람이 직접 적어야 함. 뉴스·우승 소식·영상은 자동.
- 구장 정보는 지자체 공개 자료 기준이라 증설·변경이 늦게 반영될 수 있음 → 제보받으면 `data/manual_overrides.json` 에 적고 `scripts/build.py` 실행.
- 틀린 대표 사진: 주소를 `data/photo_blocklist.json` 에 넣고 `scripts/photos.py --retry` (카카오 키 필요).
- 내 PC 에서 회원 기능 시험: `$env:DEV_LOGIN = "1"` 후 `.venv\Scripts\python app.py` → 로그인 화면의 시험용 로그인 ('시험회원' = 관리자). 자료는 `data/community.db` (git 제외).
- 이용약관·개인정보처리방침은 일반 기준으로 쓴 초안. 사업 확대 시 전문가 검토 권장.
- Render 무료 서버: 15분 접속이 없으면 잠들고 첫 접속에 30초~1분.
