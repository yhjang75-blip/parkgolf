## 2. 다음에 이어서 할 일 (순서대로)

1. **Render 에 DB 연결 확인** ← 여기서 멈춤
   - Neon 프로젝트 '나이스파크'(싱가포르) 생성 완료. 사용자가 접속 주소를 Render 에 넣었다고 했으나 공개 사이트는 아직 DB 를 못 찾음 (`/api/me` → `{"enabled":false}`).
   - 확인할 곳: Render → parkgolf → **Environment** 에 `DATABASE_URL` 이 있는지, **Logs** 에서 `데이터베이스` / `회원 기능` 검색.
   - 로그 문구 뜻: `DATABASE_URL 이 없습니다` = 값이 안 들어감 · `연결 실패 … password` = 비밀번호 틀림 (Neon 에서 Reset password 후 다시 넣기) · `연결 성공` = 완료.
   - Neon 화면에서 '비밀번호 표시'·'코드 조각 복사'를 누르면 오류 화면이 나왔음 → **Reset password** 로 새 주소를 받는 방법을 씀.
2. **카카오 로그인 켜기** (카카오 개발자 → 앱 '파크골프장 통합예약시스템', ID 1646134)
   - 카카오 로그인 사용 ON
   - Redirect URI: `https://parkgolf.onrender.com/auth/kakao/callback`, `http://localhost:5000/auth/kakao/callback`
   - 동의항목: 닉네임·프로필 사진 필수
   - Render Environment 에 `KAKAO_REST_API_KEY` 추가 (대화에 노출된 기존 키는 재발급 권장)
3. **공개 사이트에서 가입·글쓰기·사진 올리기 확인**
4. **관리자 지정**: 운영자가 가입 → '내 정보' 아래 회원번호(`kakao:숫자`) 확인 → Render 에 `ADMIN_KAKAO_IDS` 추가
5. **운영 정보 채우기** (`data/site.json`): 운영자 이름(개인정보 보호책임자), 문의 이메일, 제휴 문의처 — 개인정보처리방침에 법적으로 필요
6. **제휴 혜택 등록**: 제휴처·상품이 정해지면 `/admin` 에서 등록

## 3. 알아 둘 점

- 대회 일정(`data/media.json` 의 `tournaments`)은 사람이 직접 적어야 함. 뉴스·우승 소식·영상은 자동.
- 구장 정보는 지자체 공개 자료 기준이라 증설·변경이 늦게 반영될 수 있음 → 제보받으면 `data/manual_overrides.json` 에 적고 `scripts/build.py` 실행.
- 틀린 대표 사진: 주소를 `data/photo_blocklist.json` 에 넣고 `scripts/photos.py --retry` (카카오 키 필요).
- 내 PC 에서 회원 기능 시험: `$env:DEV_LOGIN = "1"` 후 `.venv\Scripts\python app.py` → 로그인 화면의 시험용 로그인 ('시험회원' = 관리자). 자료는 `data/community.db` (git 제외).
- 이용약관·개인정보처리방침은 일반 기준으로 쓴 초안. 사업 확대 시 전문가 검토 권장.
- Render 무료 서버: 15분 접속이 없으면 잠들고 첫 접속에 30초~1분.

## 2026-11-17 대회 참가 시스템 추가 (파크모아·파크다 벤치마킹)

- 메뉴 '대회 참가' (`/compete`) 신설. 기존 '대회 안내'(`/tournament`)는 다른 기관 대회 일정 안내로 유지.
- 흐름: 관리자가 대회 개설 → 회원이 신청(이름·휴대폰·성별·출생연도·소속·부문) → 관리자 입금 확인(참가 확정, 30P) → 자동 조편성(부문별, 같은 클럽 분산, 코스·홀 샷건 출발) → 코스별 타수 입력 → 부문별 순위(동타는 뒤 코스부터 비교) → 결과 공개.
- 회원 화면: 대회 목록·상세(정원 막대, D-day, 내 신청 진행 단계, 내 조·출발 홀·시각), 신청·수정·취소(입금 후 취소는 '취소요청'), 내 정보에 '내 대회 참가'.
- 관리자: 관리자 화면 → '대회 개설·참가자 관리'. 공개/마감/조편성 공개/결과 공개 버튼, 신청자 명단 CSV, 인쇄용 조편성표·조별 점수카드·결과표.
- 공개 화면에는 이름 가운데 글자를 가림(김*수). 연락처·입금 안내는 본인·관리자만 봄. 개인정보처리방침에 항목·보관기간(대회 종료 후 1년) 추가.
- 코드: `compete.py`, `db.py`(comps·entries 표), `templates/compete_*.html`, `static/compete.css`.
- 아직 없음(다음 후보): 문자 알림, 계좌 입금 자동 확인, 심판용 휴대폰 점수 입력(QR), 단체전, 협회·클럽이 직접 대회를 여는 주최자 계정.

## 2026-11-17 파크골프 점수계산기 (연습게임) 추가

- 메뉴 '점수계산기' (`/score`). 로그인·DB 없이 휴대폰 브라우저(localStorage)에만 저장 → DB 연결 전에도 사용 가능.
- 명단 입력: 한 줄에 이름 칸 + [남][여] 버튼, 엔터로 다음 줄, 여러 이름 붙여넣기 시 자동으로 줄 나눔 (2026-11-17 변경, 쉼표·빈 줄 팀 지정 방식은 없앰).
- 설정: 9/18홀, 홀별 파(기본 3,4,3,4,5,3,4,3,4 = 33), 팀 인원(2~6, 기본 4), 팀 점수 방식(전원 합계 / 잘 친 3명 합계), 명단 붙여넣기(한 줄 한 명, (여) 표시, 쉼표·빈 줄로 팀 직접 지정, 무작위 섞기). 최대 20팀.
- 입력: 팀·홀 선택 → 선수별 [−][타수][+] (가운데 누르면 파), 빈칸 모두 파.
- 전체표(홀별 색: 홀인원·이글·버디·파·보기·더블+), 실시간 순위(개인·팀·남자부·여자부, 진행 중엔 ±, 끝나면 총타수·마지막 홀부터 역순 비교), 시상(개인·팀 1~3위, 남녀 1위, 홀인원, 버디왕), 결과 공유(카톡 붙여넣기 문구)·인쇄.
- 휴대폰 여러 대: 설정 → 팀별 '링크 보내기' → 팀 폰에서 입력 후 '점수 보내기' → 총무가 받은 메시지를 '받은 점수 붙여넣기'에 넣으면 합쳐짐 (게임 번호가 다르면 거부).
- 코드: `templates/score.html`, `static/score.js`, `static/score.css`, `app.py` /score.
- 다음 후보: DB 연결 후 실시간 자동 합산(링크 붙여넣기 없이), 지난 게임 기록 보관.
